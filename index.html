Three steps, then the file leaves the chat.

01

Bring the HTML

Upload the file an LLM generated, or paste the markup. Two sample decks are built in if you want to see the edit before you have a file.

02

Click what is wrong

Text becomes editable where you click. Images can be replaced. When the file is a deck, slides can be duplicated, deleted, and reordered.

03

Hand it back

Download one HTML file, print to PDF, or copy a link. The link holds the compressed deck, so the next person opens it ready to edit. No server stores it.

What the editor actually does

Inline text

Click a heading, a figure, or a caption. Undo and redo cover the session, and the browser keeps the latest copy.

Images

Click an image and choose a replacement. The new file is embedded, so the export does not depend on the original path.

Slides, when the markup has them

Recognizes reveal.js sections, sibling .slide elements, and sibling section elements. Anything else is one document.

A link instead of an account

Share encodes the deck with lz-string into the URL hash. If the deck is too large, TechyDeck says so and offers the download.
